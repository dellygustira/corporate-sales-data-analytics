# Corporate Sales Performance & Customer Retention Optimization

## 📊 Project Overview
This project delivers a data-driven business intelligence and data analytics solution designed to evaluate corporate revenue streams, identify high-profit regional portfolios, and analyze customer attrition risks (Churn Analysis). Leveraging transactional sales datasets, this analysis bridges technical data processing with strategic corporate decision-making.

## 🛠️ Tech Stack & Tools
* **SQL (SQLite):** Data extraction, filtering, and multi-dimensional aggregations.
* **Python (Pandas, Seaborn, Matplotlib):** Data preprocessing, cleaning missing values, and exploratory data analysis (EDA).
* **Google Colab:** Cloud-based interactive notebook environment (`SuperStore.ipynb`).
* **Power BI / Tableau:** Executive dashboard architecture and data visualization design.

## 📈 Key Business Insights & Objectives
1. **Product Line & Regional Profitability:** Identified top-performing product categories and isolated low-margin regional portfolios to optimize operational expense (OpEx) allocation.
2. **Customer Retention & Churn Mitigation:** Structured behavioral data tracking to flag at-risk accounts, enabling proactive loyalty strategies.
3. **Commercial Growth Drivers:** Evaluated transaction volumes against gross income margins to support data-driven pricing and promotional decisions.
